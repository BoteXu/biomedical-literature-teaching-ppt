# 叙事、覆盖度与讲稿

## 使用模式

**文献汇报**：理解作者的难题、研究对象、中心假说和主要结论，按证据链选图，说明每项实验为何出现、排除了什么、还留下什么。可按背景缺口、设计、关键发现、机制验证、局限、对自己课题启发组织；不固定页数，也不机械照全文逐图念。

**教学**：确定学生要学会的研究判断，用真实论文把方法嵌进去。基础概念和常规分析讲清，再进入新工具；每项工具要承担问题链中的任务。混合模式如“用一篇心肌病论文教多组学整合”，由实际论文约束展开。有限时组会不要自动塞入全部方法。

## 问题链与覆盖

每页先写：上一证据仍不能回答 X，所以作者用 Y 测量/检验 Z；当前图显示 A，支持 B，留下 C。用它决定选图和顺序，屏幕标题只保留问题或图能支持的结论。

问题链用于决定选图与顺序，口播用自然叙述连接研究进展，不在每页机械解释“为什么接在上一页后面、如何引出下一页”。

同一方法可分为问题缺口、原理、实际结果、伪差排除和验证页；同一科学面板不反复充当主证据。确需复现时登记教学理由或用户认可。

“大而全”检查维度如下，按主题、受众和时间选取，不作为固定必讲目录：

| 层级 | 问题 |
|---|---|
| 设计 | 对象、比较组、干预、时间、独立重复、混杂和功效是什么？ |
| 测量 | 直接测到什么？新旧方法补哪类缺口？ |
| 预处理 | 质控、归一化、缺失、批次、注释和样本对应如何影响结果？ |
| 常规分析 | 降维、聚类、差异、组成、关联、富集、网络和可视化解决什么？ |
| 推断 | 轨迹、通讯、调控、整合、遗传、结构/生成预测依赖什么假设？ |
| 验证 | 独立样本、外部数据、原位、生化和功能扰动怎样检验？ |
| 推广 | 跨物种、组织、祖源、疾病或平台时哪些条件要重建？ |

组学可展开空间 RNA/蛋白、表观、蛋白/修饰、代谢/脂质/通量、翻译、微生物、遗传和整合。计算可展开统计学习、网络、结构、对接、动力学、采样/自由能、机器学习势、扩散/生成；均有实际论文和验证任务，不能以名称覆盖替代讲解。

## 每张图讲透什么

1. 论文、年份、物种、疾病/组织、模型、组别、独立样本单位。
2. 前一步缺什么？为什么选此技术？
3. 实际输入：组织/细胞/序列/结构/计数/谱图及条件与标签。
4. 实验怎样转为信号；计算怎样转为统计量或预测；关键假设。
5. 每个可见面板的轴、量纲、颜色、点/条/边单位、对照、方向和不确定性。
6. 直接观察、统计推断和作者解释分别是什么；只讲可见证据。
7. 一项针对当前图的替代解释，以及区分它的实验和预期读出。

不同图形使用自己的语义，不能都套横纵轴模板：

- 流程：箭头顺序、实验/计算步骤、配对关系和质量控制。
- 显微：标记、通道、比例尺、病灶、分割/共定位、独立切片。
- 凝胶/印迹：泳道、目标、载荷对照、归一化和对应量。
- 降维：点和颜色的单位、嵌入距离限度；UMAP/t-SNE 轴不是实测生物量。
- 点图/热图：尺寸/颜色各编码什么，行列单位、归一化和分母。
- 遗传：关联位点、变异、LD、效应基因和药物靶点的推断层级。
- 结构：实验/预测、构象状态、置信度、几何与结合的关系。
- 动力学：体系、重复、时间/单位、参考、相关帧和收敛。
- 生成：实测/生成、训练/测试切分、适用域和外部验证。
- 封面/转场：证据链与学习任务，不编造读轴结果。

## 真正口播与蓝色批注

口播正文能直接讲并包含解答。例如：

> 大家先看横轴，这是基因组位置。纵轴越高表示关联检验的 P 值越小。一个峰里通常有多个相互相关的变异，所以这张图先给出关联区域。要把区域连到基因，还需要精细定位、相关组织的 QTL 和功能实验。仅凭这一页能否认定最近的基因就是致病基因？不能，因为连锁结构和远端调控都可能让它指向另一个基因。

蓝色批注给教师：指图顺序、停顿、常见误区、术语、答案提示、转场和待核对项。Word/PowerPoint 使用蓝色文字；用户明确要求 Office 原生评论时才建立评论对象，不能把蓝色段落称为原生评论。

不能用“请学生看坐标/去查原文/填写输入/讲者给出答案”代替口播。每页原理根据实际方法确定，注意历史平台差异，例如早期扩增式单细胞不能套用后来液滴 UMI 流程。

## 时长

有每页最低时长才实施下限，否则按整场时间分配。五分钟可展开研究问题、逐图观察、原理与输入输出、结果推理、反证与有答案的互动；各段分配随图复杂度变化。

中文教学可用 180 汉字/分钟、英文 130 词/分钟作规划起点。它是估计，受术语、语速与停顿影响。正文时长与计划看图/互动分开报告，不能保证现场时长。要求口播五分钟时，正文自身按声明语速达到下限并留余量，不能靠预计学生回答补足。

只计 spoken_text，不计标题、出处、原文图注、教师指令和未口播资料。图解释索引不能重复计数。具体术语和缩写要解释，不把长 DOI/编号当讲课。

扩写当前图特有的对照、单位、假设、步骤、两个可能解释、一项验证及怎样读其结果。不要批量粘贴“图谱不是机制”“分数不是药效”等通用段落凑时长；必要回顾应连接当前实例。

## 科学边界

区分观察、关联、推断、外部预测和干预支持。细胞数不等于患者数；组成变化不等于细胞内改变；拟时序不等于实际时间；RNA 配体受体共表达不等于通讯；代谢池不等于通量；修饰肽需核对总蛋白；关联峰不等于因果变异；对接分数不等于亲和力；轨迹稳定不等于药效；生成结构不等于实验命中。

针对当前图应用边界，不机械逐页复制。样本数、统计量、方向和术语不能从相邻页迁移。旧备注与原文冲突时回查原文，记录修订依据。

## 精简已有课件

按用户目标压缩篇幅时，先标记每页承担的研究问题、分析步骤与证据任务。优先删除重复面板、工具名称堆叠、超出受众需要的工程细节与冗长质控评测。保留必要输入、关键质控判断、常规分析、结果解释和验证；不机械按页抽样。同步更新页码、图源、PPT备注和Word逐页讲稿，修复对已删页面的依赖句。
