# 图与最终导出检查

## 完整且可读

完整可以是整图或独立完整子面板。选面板时保留轴、图例、比例尺、组名、误差线和必要对照，不切过数据/标签。未展示面板不得作为当前屏幕证据。

原图文件自身也可能截断，不能只查 PPT 裁切设置。不要用白块、空白或标题遮住残缺边缘。图过宽/高时调整布局、完整放入新页或拆面板；每页重新确定叙事任务。

通常优先出版社高分辨率/矢量图、开放原文图、PDF 提取、最后浏览器截图。截图前确认全图加载并读图注，不把视口里的半张图当完整原图。

## 逐页检查

在最新渲染上逐页登记：

| 项目 | 通过标准 |
|---|---|
| 范围 | 页面内，无重叠、遮挡、溢出 |
| 完整 | 面板、轴、图例、比例尺和必要标签完整 |
| 可读 | 展示尺寸下关键标签可读，分辨率足够、无变形 |
| 对应 | 图源、屏幕面板与讲稿一致 |
| 密度 | 少字、焦点明确，复杂图通过拆页可读 |
| 唯一 | 无同科学面板复用，例外/模板有理由 |
| 语义 | 单位、颜色、模型、比较与统计解释准确 |
| 备注 | 完整口播、逐图说明、蓝色提示对应当前页 |

接触图验证漏页、顺序和大尺度异常；看不清的标签用单页放大。全部页视觉检查必须实际逐页观察并登记，自动边界扫描或抽查不能替代。

## 自动检查限度

inventory 按实际页序导出全文、备注、图片关系/哈希、OOXML 裁切、显式边界与重复媒体候选。

- srcRect 是复查线索，合法完整面板选取也可能有裁切。
- 相同媒体不同裁切可能是不同面板；不同媒体也可能是同面板重编码。
- 简单矩形越界可检测；分组、旋转、母版继承和遮罩需视觉判断。
- 原图半截、小字、标签遗漏、字体替代和科学错误不能由脚本认证。

compare-decks 比较可视相关 ZIP 部件与页序/尺寸，可以支持“只改备注，保留了这些部件”的结构性判断，不等价于跨软件像素一致或已全部页检查。

## 导出验证

1. 最新源另存输出，确认可打开、页数、页序、媒体显示。
2. 按演示文稿技能渲染全部页；实际 PowerPoint 可用时可进一步打开检查。用已配置运行时，不为一次导出安装系统套件。
3. 改图/布局后重渲染相关页，以文件哈希/时间区分新旧，不验旧图交新文件。
4. Word 按 Documents 技能渲染。配置渲染器不可用且 Windows Word 可用时，可由 Word 导出 PDF 后栅格化检查，打开成功不代表排版通过。
5. 核对所有幻灯片页码、蓝色段落与口播覆盖；PDF 文字页数可多于 PPT 页数。
6. 原生评论额外核对评论对象/锚点/关系，PDF 不一定显示。
7. 结构、边界、空白、缺页与视觉检查分别登记与报告。

QA 字段可用 slide、export_sha256、render_file、visual_review、readable_at_presentation_size、complete_visible_panels、issues、repairs、rechecked_after_last_edit、scientific_source_review。没有实际核对的写 pending/not_checked；不得依据脚本通过自动填 pass。
